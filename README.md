# Online Shop API

RESTful API for an online store built with Spring Boot, Java 17, PostgreSQL, Docker JWT authentication 
and role‑based authorization.


## Technologies
- **Java 17**
- **Spring Boot 3**
- **Spring Data JPA / Hibernate**
- **Spring Security**
- **Flyway**
- **Swagger UI**
- **Docker**
- **JWT**
- **Hibernate**
- **H2 Database**
- **Lombok**
- **Maven**


## Installation and launch

### Preliminary requirements

* Java 17+;
* Maven 3.6+;
* IDE (IntelliJ IDEA, Eclipse и т. д.) или текстовый редактор.
